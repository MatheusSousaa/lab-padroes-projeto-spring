# Padrões de Projeto com Java e Spring

Projeto desenvolvido com Java e Spring Framework, aplicando padrões de projeto para melhorar a organização e a estrutura do código.

## Padrões utilizados

- **Singleton**
- **Strategy**
- **Repository**
- **Facade**

## Melhorias implementadas

- Programação defensiva e validação de dados.
- Exceções personalizadas para tratamento de erros.
- Injeção de dependências por construtor.
- Utilização do Lombok para reduzir código repetitivo.

## Tecnologias

- Java
- Spring Framework
- Spring Data JPA
- OpenFeign
- Lombok
- Maven

## Objetivo

Aplicar padrões de projeto e boas práticas de desenvolvimento para construir uma aplicação mais organizada, reutilizável e fácil de manter.
